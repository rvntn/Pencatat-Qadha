# Pencatat-Qadha
Pencatat Qadha Sholat dan Jadwal Waktu Sholat

## Cara Menggunakan
1. Unduh dari [release](https://github.com/rvntn/Pencatat-Qadha/releases/latest)
2. Letakan file exe di folder khusus (diperlukan folder khusus karena file "exe" akan meletakan file "ini")
3. Jalankan file exe.

## Membangun dari Kode Sumber
### Prasyarat
1. [rust](https://rustup.rs/)
### Compile
```sh
cargo build --release
```
